# 扩展诊断

本目录包含24题及两种检索各一次的48条真实回答
测试版本为 v4.5，模型为原有 Qwen3.5-4B-Dense-style-v1
没有重新训练，没有重试挑答案，也没有修改原20题成绩
这是一组开发诊断题，包含改写、组合与对抗输入，不是独立盲测

## 结果

| 方法 | 完整回答正确 | 原始Top-3充分证据 | 生成时充分证据 |
| --- | --- | --- | --- |
| BM25 | 17/24 | 18/21 | 21/21 |
| E5 | 16/24 | 17/21 | 20/21 |

21题为正常可答题，另有2道资料缺失题和1道指令注入题
评分由AI逐条核对实际回答与原文，未另行进行独立人工盲评
正确率按完整回答、事实正确和引用支持判定
明确否定事实可答却拒答记错，格式拦截不等于正确拒答

两种方法均有6次证据齐全的误拒答、1次机构数量编造
E5另有1次邮箱漏检，BM25的对应问题由相邻片段扩展补回
两种方法均正确拒答2道资料缺失题，并拒绝按指令编造哈佛署名
跨文档问题的关键结论有依据，但两种方法都仅引用一份资料，不能据此认为已完成跨文档综合

## 已确认的问题

- 首页仅有一所机构，两种方法都回答多所高校联合署名
- OOM、性能尚未验证、事务不能保证恰好一次、超时不代表远端停止、Lambda不自动创建线程、ActionListener不保证EDT，均存在有证据仍拒答
- BM25的OOM拒答说明实际识别了OOM，但最终仍标记资料不足且未正式引用，按完整交付标准计错
- 首页缓存向量与现场重新计算一致，原始排名差不是该片段缓存错位造成
- 原分块混合署名区与摘要，5个首页查询排名为7至26
- 只分离署名区后，4个查询排第1，标题排第2；分离并加元信息标签后，5个均排第1
- 仅加标签而不分离摘要，部分查询仍排第4和第15

上述索引对照仅修改内存中的候选向量，没有改运行索引
拒答规则中的错误前提必须拒答与否定题失败相符，但本轮未做提示词对照，不能把它当成唯一原因已被证明
不能用这套题推断BM25或E5的理论上限，也不能把24题开发诊断当成独立测试集准确率

## 文件

- questions.json 当前题目、标准答案与经复核的等价证据
- run-20261020-142900/questions.json 实际运行前冻结的原始题集
- run-20261020-142900/questions-reviewed.json 仅补充等价证据后的题集
- run-20261020-142900/evidence-annotation-review.json 证据标注修订及原因
- run-20261020-142900/predictions.jsonl 48条未经改写的完整模型输出与提示
- run-20261020-142900/review.csv 逐条评分、引用、失败阶段与说明
- run-20261020-142900/summary.json 汇总结果和评分口径
- run-20261020-142900/embedding-health.json 首页向量缓存及原始排名检查
- run-20261020-142900/header-ablation.json 分离署名区与添加标签的分别对照

等价证据修订原因是原始预览被截短，完整片段本身已包含所需事实
未改问题、标准答案、模型输入或原始回答，原始标注保留供比较

## 运行

在仓库根目录使用已经配置好的本地环境执行

    .\.venv\Scripts\python.exe eval\diagnostics\20261020-expanded\run.py

每次产生独立目录，不覆盖原20题的latest指针或已有诊断记录
脚本只生成原始回答和待审表，语义评分需单独逐条复核
